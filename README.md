# Air Traffic Control System in Java

## Overview
This project is an implementation of an Air Traffic Control (ATC) system in Java. The system manages the movement of aircraft within controlled airspace, ensuring safe and efficient air traffic operations.

## Installation
1. Ensure you have Java installed on your system.
2. Clone the repository:

    ```bash
    git clone https://github.com/yourusername/air-traffic-control.git
    ```

3. Navigate to the project directory:

    ```bash
    cd air-traffic-control
    ```

4. Compile the Java files:

    ```bash
    javac *.java
    ```

5. Run the application:

    ```bash
    java AirTrafficControl
    ```

## Usage
1. Upon running the application, the GUI will be displayed.
2. Use the GUI to register new aircraft, monitor their movements, and issue instructions.
3. The system will handle collision avoidance and update aircraft positions in real-time.

## Dependencies
This project has no external dependencies beyond the standard Java libraries.
